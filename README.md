## Editing the site

The pages are plain HTML generated by a small Python script, so text changes happen in one place:

1. Business details, services, industries, FAQs and cities are in `_build/content.py`.
2. Collections are JSON files in `_build/data/`:
   - `ad_platforms.json`: the paid ads platform pages
   - `portfolio.json`: portfolio projects
   - `articles.json`: Insights articles
   - `locations.json`: city pages
3. Layout and page structure are in `_build/build.py`; styles in `assets/css/styles.css`; scripts in `assets/js/main.js`. The colours (sky blue and navy) are CSS variables at the top of `styles.css`.
4. Rebuild (Python 3, no dependencies):

   ```bash
   python3 _build/build.py
   ```

5. Commit the regenerated HTML.

## Home page hero

The home page hero has two optional extras, both set in `_build/content.py`. Rebuild after changing either.

- **Photo:** while `HERO_PHOTO` is empty, the blue circle shows an illustration of enquiries arriving on a phone. To show a real photo instead, such as the owner or a team member (with their permission), put a portrait image in `assets/img/` (a cut-out PNG with a transparent background looks best), set `HERO_PHOTO = "assets/img/hero-photo.png"` and put the person's name and role in `HERO_PHOTO_ALT`.
- **Google rating:** `GOOGLE_REVIEWS` adds a Google rating row under the hero's three trust points. Leave it empty until the business has real Google reviews. Then enter the real rating, review count and review link, for example `{"rating": "4.9", "count": "38", "url": "https://g.page/r/your-review-link"}`, and update the figures as they change. Never enter made-up or rounded-up numbers.

## Google Analytics

Set `GA_MEASUREMENT_ID` in `_build/content.py` to your GA4 Measurement ID (it looks like `G-XXXXXXXXXX`) and rebuild. The GA4 tag is then added to every page, and these events are sent automatically:

| Event | When |
| --- | --- |
| `whatsapp_click` | A visitor clicks any WhatsApp link |
| `phone_click` | A visitor clicks a phone number |
| `email_click` | A visitor clicks an email address |
| `generate_lead` | A visitor sends the contact form (to WhatsApp or email) |

Mark `generate_lead` and `whatsapp_click` as key events in GA4. If you expect visitors from the UK or EU, add a cookie consent banner before switching analytics on.

## Hosting

The site is hosted on **Vercel**, which is connected to this GitHub repository:

- Every push to `main` publishes the live site.
- Every pull request gets its own preview link, posted on the pull request by the Vercel bot.
- Vercel serves the committed HTML as it is, with no build step. After editing anything in `_build/`, run `python3 _build/build.py` and commit the regenerated pages.
- `.vercelignore` keeps `_build/` and this README off the live site.
- `404.html` is used automatically for missing pages.

To use `smartclick.co.zw`:

1. Add the domain in Vercel under the project's **Settings > Domains**.
2. Wherever you manage the domain, add the DNS records Vercel shows you. Leave the email (MX) records as they are.

HTTPS is set up automatically once the records are in place.

It's a plain static site, so any other host works too (cPanel, Netlify, Cloudflare Pages, GitHub Pages): upload everything except `_build/` and `README.md`, and set `404.html` as the error page. No server or database is needed. The contact form opens WhatsApp (or the visitor's email app) with their details filled in, so enquiries arrive on 0771 269 979 or at info@smartclick.co.zw.
