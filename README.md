## Editing the site

The pages are plain HTML generated by a small Python script, so text changes happen in one place:

1. Business details, services, industries, FAQs and cities are in `_build/content.py`.
2. Collections are JSON files in `_build/data/`:
   - `ad_platforms.json`: the paid ads platform pages
   - `portfolio.json`: portfolio projects
   - `articles.json`: Insights articles
   - `locations.json`: city pages
3. Layout and page structure are in `_build/build.py`; styles in `assets/css/styles.css`; scripts in `assets/js/main.js`.
4. Rebuild (Python 3, no dependencies):

   ```bash
   python3 _build/build.py
   ```

5. Commit the regenerated HTML.

## Google Analytics

Set `GA_MEASUREMENT_ID` in `_build/content.py` to your GA4 Measurement ID (it looks like `G-XXXXXXXXXX`) and rebuild. The GA4 tag is then added to every page, and these events are sent automatically:

| Event | When |
| --- | --- |
| `whatsapp_click` | A visitor clicks any WhatsApp link |
| `phone_click` | A visitor clicks a phone number |
| `email_click` | A visitor clicks an email address |
| `generate_lead` | A visitor sends the contact form (to WhatsApp or email) |

Mark `generate_lead` and `whatsapp_click` as key events in GA4. If you expect visitors from the UK or EU, add a cookie consent banner before switching analytics on.

## Hosting

The site is published to **GitHub Pages** by `.github/workflows/deploy-pages.yml` every time `main` changes. The workflow rebuilds the pages from `_build/` first, so an edit to `content.py` goes live even if the HTML wasn't rebuilt. You can also run it by hand from the Actions tab ("Deploy website", then "Run workflow").

One-time setup:

1. In the repository, open **Settings > Pages** and set **Source** to **GitHub Actions**.
2. Under **Custom domain**, enter `smartclick.co.zw` and save.
3. At your domain registrar, add these DNS records:
   - `A` records for `smartclick.co.zw` pointing to `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`
   - a `CNAME` record for `www` pointing to `tanakafoster.github.io`
4. Once the domain check passes (DNS can take up to a day), tick **Enforce HTTPS**.

Until step 1 is done, the workflow skips publishing and leaves a warning instead of failing.

It's a plain static site, so any other host works too (cPanel, Netlify, Cloudflare Pages): upload everything except `_build/`, `.github/` and `README.md`, and set `404.html` as the error page. No server or database is needed. The contact form opens WhatsApp (or the visitor's email app) with their details filled in, so enquiries arrive on 0771 269 979 or at info@smartclick.co.zw.
